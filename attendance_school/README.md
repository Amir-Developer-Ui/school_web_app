# سامانه حضور و غیاب هنرستان — MVP

## امکانات فعلی
- ورود مدیر با حساب Django
- تعریف کلاس بر اساس ۹ رشته و پایه‌های دهم تا دوازدهم
- افزودن گروهی دانش‌آموزان (هر خط: نام و نام خانوادگی)
- ثبت حاضر / غایب / تأخیر برای هر کلاس و تاریخ شمسی
- بازیابی اطلاعات قبلی هنگام بازکردن مجدد کلاس
- گزارش روزانه و متن آماده کپی برای بله
- موجه‌سازی و برگشت موجه‌سازی غیبت
- دریافت فایل پشتیبان SQLite
- رابط فارسی، راست‌چین و واکنش‌گرا

## اجرا در ویندوز
1. Python 3.11 یا جدیدتر نصب باشد.
2. در پوشه پروژه ترمینال باز کنید:
   `py -m venv .venv`
3. فعال‌سازی:
   `.venv\\Scripts\\activate`
4. نصب وابستگی‌ها:
   `pip install -r requirements.txt`
5. ساخت دیتابیس:
   `python manage.py migrate`
6. ساخت حساب مدیر:
   `python manage.py createsuperuser`
7. اجرا:
   `python manage.py runserver`

سپس آدرس `http://127.0.0.1:8000` را باز کنید.

## نکات مهم پیش از استفاده واقعی
- این نسخه MVP است و برای آزمایش اولیه طراحی شده؛ پیش از استقرار عمومی، `DEBUG=False`، مقدار امن `SECRET_KEY`، `ALLOWED_HOSTS` محدود، HTTPS و تنظیمات امنیتی سرور الزامی است.
- برای دسترسی هم‌زمان گوشی و کامپیوتر، پروژه باید روی یک سرور/هاست قابل دسترس در شبکه مدرسه یا اینترنت نصب شود. `runserver` فقط برای توسعه است.
- SQLite برای شروع و حجم این مدرسه مناسب است؛ اگر چند اپراتور هم‌زمان یا استقرار جدی داشتید، PostgreSQL گزینه مناسب‌تری است.
- تاریخ‌ها در رابط به صورت شمسی وارد می‌شوند و در دیتابیس به صورت تاریخ استاندارد میلادی ذخیره می‌شوند.
- نسخه فعلی امکان حذف کلاس/ویرایش اطلاعات دانش‌آموز را در رابط کامل نکرده است؛ این موارد برای مرحله بعدی در نظر گرفته شده‌اند.
- بکاپ را به‌صورت دوره‌ای دانلود و در محل امن جداگانه نگهداری کنید. فایل دیتابیس حاوی اطلاعات دانش‌آموزان است.

## مدیریت و پاک‌سازی اطلاعات
- از صفحه «کلاس‌ها و دانش‌آموزان» می‌توان مشخصات کلاس را ویرایش یا کلاس را حذف کرد. حذف کلاس، دانش‌آموزان و سوابق حضور و غیاب همان کلاس را نیز حذف می‌کند.
- در صفحه هر کلاس، روی نام دانش‌آموز بزنید تا نام، نام خانوادگی، شماره پرونده و کلاس او را ویرایش یا دانش‌آموز را حذف/منتقل کنید. حذف دانش‌آموز، سوابق حضور و غیاب وابسته به او را نیز حذف می‌کند.
- گزینه «تنظیمات و پاک‌سازی» فقط برای حساب مدیر (superuser) نمایش داده می‌شود. پاک‌سازی با واردکردن رمز عبور حساب و عبارت دقیق «پاکسازی کامل» انجام می‌شود. این عملیات کلاس‌ها، دانش‌آموزان و سوابق حضور و غیاب را حذف می‌کند، اما حساب مدیر را نگه می‌دارد.
- پیش از پاک‌سازی، از همان صفحه نسخه پشتیبان SQLite دریافت کنید. پاک‌سازی قابل بازگشت نیست.
